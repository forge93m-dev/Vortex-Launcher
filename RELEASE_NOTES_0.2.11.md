# Vortex Launcher 0.2.11 — animated capes in your Vortex account, Vortex Client 0.2.7

## Vortex Client 0.2.7

- **Animated capes are saved in your Vortex account.** If you are signed in to Vortex, publishing an animated cape
  no longer asks for an activation code, and other players with the client see it. Up to 120 frames, 20 ms per frame, 512 wide.
- Fixed: publishing an animated cape could end with "Publication unconfirmed / No saved access for this profile".
- Existing instances: use **Update Vortex Client**. Worlds, mods and settings are preserved.

## Launcher

- No other launcher changes since 0.2.10.

## Notes

- The Vortex account service was updated first, so this works as soon as you update.
- Only Minecraft 26.3 is the main target; 26.2, 26.1.2, 26.1.1, 26.1 and 1.21.11 stay experimental.
- Checked by automated tests; not played through on every version.

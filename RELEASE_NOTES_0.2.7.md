# Vortex Launcher 0.2.7 — Vortex Client 0.2.3

## Correction to 0.2.6

The 0.2.6 notes listed new Vortex Client features, but the client bundled in 0.2.6 was still
version 0.2.2 and did not contain them. This release ships the real client.

## Vortex Client 0.2.3

- Party chat and shared waypoints.
- Better chat (tabs) and a new player list.
- New interface with accent colours and smooth menus.
- Animated capes (the online cape service is not switched on yet).
- Zoom, and a panorama picker for the main menu.
- Exact builds for Minecraft 26.3, 26.2, 26.1.2, 26.1.1, 26.1 and 1.21.11 (Fabric).
  Only 26.3 is the main target; the others stay experimental.
- Existing instances: use **Update Vortex Client**. Worlds, mods and settings are preserved.

## Launcher

- No other launcher changes since 0.2.6 (NeoForge, CurseForge import and per-instance Java/RAM settings
  are described in the 0.2.6 notes).

## Checks

- Client: each Minecraft version passed the mixin check; 1.21.11 also the production remap check.
  Not tested by playing the game on every version.
